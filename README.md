# Essha Designz – Official Website (Client Project)

This repository contains the source code for the official website of **Essha Designz**, a bespoke office and hotel furniture brand.

## 📌 Project Type
Client Website Development

## 🏢 Client
Essha Designz – Bespoke Office & Hotel Furniture

## 🎯 Project Objective
- Build a professional and modern website
- Organize a large product catalog clearly
- Ensure responsive design across devices
- Improve user experience and navigation

## 🧰 Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Responsive Design

## ✨ Key Features
- Multi-category product navigation
- Clean UI aligned with brand identity
- Mobile-friendly layout
- Optimized performance and structure
